# 📊 Análisis de Sentimientos y Ponderación de Comentarios

Aplicación desarrollada en Python con Streamlit para analizar sentimientos en textos y comentarios. Incluye funcionalidades de ponderación de polaridades y análisis de archivos CSV.

## 🎯 Objetivo

Desarrollar una herramienta interactiva que facilite el análisis de opiniones y comentarios, permitiendo explorar sus sentimientos y visualizar los resultados obtenidos.

## ✨ Funcionalidades

- 📝 Análisis individual de comentarios.
- ⚖️ Ponderación de sentimientos mediante valores de polaridad.
- 📂 Análisis de comentarios almacenados en archivos CSV.
- 📊 Visualización gráfica de los resultados.
- 🌐 Funcionalidad de traducción y análisis mediante TextBlob, según la implementación del proyecto.

## 🛠️ Tecnologías utilizadas

- **Python:** lenguaje principal de programación.
- **Streamlit:** creación de la interfaz web interactiva.
- **Pandas:** procesamiento y organización de los datos.
- **Matplotlib:** generación de gráficas para visualizar los resultados.
- **TextBlob:** análisis de sentimientos y polaridad del texto.
- **CSV:** manejo de archivos con comentarios y datos tabulares.
- **Git y GitHub:** control de versiones y publicación del proyecto.

## 🚀 Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone https://github.com/ciberdaniel503/analisis_de_sentimientos-.git
```

### 2. Entrar en la carpeta

```bash
cd analisis_de_sentimientos-
```

### 3. Instalar las dependencias

```bash
pip install -r requirements.txt
```

### 4. Ejecutar la aplicación

```bash
streamlit run App.py
```
