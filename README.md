# 📊 Análisis de Sentimientos

Aplicación desarrollada en Python que permite analizar textos y explorar su sentimiento mediante una interfaz web creada con Streamlit.

## 🎯 Objetivo

Desarrollar una herramienta sencilla para practicar programación en Python, procesamiento de texto y creación de aplicaciones web interactivas.

## 🛠️ Tecnologías utilizadas

- **Python:** lógica y procesamiento de datos.
- **Streamlit:** creación de la interfaz web.
- **Git y GitHub:** control de versiones y publicación del código.

## ✨ Características

- Interfaz web interactiva.
- Entrada de texto para realizar análisis.
- Visualización de resultados del análisis, según las funciones implementadas en el proyecto.

## 🚀 Instalación y ejecución

1. Clona este repositorio:

   ```bash
   git clone https://github.com/ciberdaniel503/analisis_de_sentimientos-.git
   ```

2. Entra en la carpeta del proyecto:

   ```bash
   cd analisis_de_sentimientos-
   ```

3. Instala Streamlit:

   ```bash
   pip install streamlit
   ```

4. Ejecuta la aplicación:

   ```bash
   streamlit run app.py
   ```

> **Nota:** Estos pasos suponen que el archivo principal se llama `app.py`. Si tiene otro nombre o utiliza otras bibliotecas, habrá que ajustar las instrucciones.
